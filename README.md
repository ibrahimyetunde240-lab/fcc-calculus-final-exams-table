# Calculus Final Exams Table

A semantic HTML table displaying calculus final exam grades, built as part of the freeCodeCamp Responsive Web Design curriculum.

## Overview

This project demonstrates how HTML tables can be used to organize and present structured data. The table contains student names, exam grades, and the average grade.

## Features

- Table caption describing the data
- Table header using `<thead>`
- Student grade records organized with `<tbody>`
- Average grade displayed using `<tfoot>`
- Table headings using `<th>`
- Table data using `<td>`
- Use of `colspan` to combine table cells

## Technologies Used

- HTML5

## What I Learned

Through this workshop, I practiced:

- Creating tables with the `<table>` element
- Using `<caption>` to describe a table
- Structuring tables with `<thead>`, `<tbody>`, and `<tfoot>`
- Creating table rows with `<tr>`
- Creating headings with `<th>`
- Adding data with `<td>`
- Using `colspan` to span multiple columns
